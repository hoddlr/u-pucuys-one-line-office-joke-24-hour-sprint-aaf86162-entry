## What it does

`main.ts` writes a single-line joke about office life to `/output/entry.txt` (UTF-8, 104 characters, one line). The program is deterministic — every run produces the exact same output — and uses only the Node standard library.

## Run

Requires Node 22.18 or later (the grader runs Node 22.23.4):

```sh
node main.ts
```

Then read the entry:

```sh
cat /output/entry.txt
```

## Output

A one-line office joke, 104 characters:

> I asked the office plant for career advice because it's the only thing here that's grown in three years.
